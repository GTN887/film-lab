# Film Lab

Film Lab is a private AI filmmaking and virtual production platform.

## Product direction

Film Lab is being built as one connected filmmaking application around the production flow:

**Create → Direct → Produce**

Core production state:

**Project → Story → Characters / Sets → Scene → Shot → Take → Selected Take → Cinema → Export**

## Engineering standard

A screen, desk, label, or button is not considered a finished feature by itself. A feature is complete only when the intended operation works, produces the intended result, persists where required, integrates with the production flow, and passes its tests.

This private repository is the source of truth for Film Lab development.
