# Cross-Shot Action & Screen-Direction Continuity Gate

Status: **REAL software evidence / NOT MACHINE-CERTIFIED**

Film Lab now compares Creator-bound target tracks across consecutive Selected Takes. It reports boundary position changes and coarse outgoing/incoming motion direction, and it can validate explicit outgoing/incoming eyeline intent when that intent is persisted by the Shot metadata.

It is conservative: motion reversal is **REVIEW**, not automatic failure, because reverse motion and jump cuts can be intentional. Missing target/eyeline evidence remains **NOT_TESTED**. Pixel tracking does not prove Character identity, semantic action matching, gaze, or 180-degree-rule compliance.

The result is integrated into Scene Assembly cut reports and never changes Selected Takes or exports Cinema automatically.
