Each look has a **mentor note** for intimacy / sex scenes (adults only). Cinematic names are original Film Lab labels — not a show or franchise kit.

## How it injects (only if you pick one)

1. Lighting Desk, **Pipeline Enhance**, or the picker on Still / Motion Enhance / Effects / Cinema.
2. Skip writes nothing. A pick writes `active_lighting` and a prompt chip.
3. Motion Enhance and Effects fold the chip into the local prompt.
4. Cinema stamps a reel note — it does **not** re-light already-rendered clips.
5. Still Desk can fold the chip into still notes.

Nothing is uploaded. No hosted lighting API.

## How Liam should light a bedroom take

1. Open **Lighting Desk**. Skip, or start with **Practical lamps** / **Rembrandt**.
2. Read the intimacy note if the scene is graphic.
3. Lock only if you want it. Open Motion Enhance — same optional picker.
4. Generate. The still's lamp should match the chip if you picked one.
