# Project Save Library

Browse the current lot on **this PC**: stills, takes, sets, writing, and exports.

Local-first. Zero credits. Nothing is uploaded unless you ask for an optional Drive copy.

## Local shelves

| Shelf | Folder |
| --- | --- |
| Stills | `data/projects/<lot>/stills/` |
| Takes | `data/projects/<lot>/takes/` |
| Sets | `data/projects/<lot>/sets/` |
| Writing | `data/projects/<lot>/writing/` |
| Exports | `data/projects/<lot>/outputs/` |

Open **Library** in the top nav (not a Home hub card). Pick a shelf. **Browse this PC**.

## Optional OneDrive / Google Drive

Paste a folder that the **desktop** OneDrive or Google Drive app already syncs. Film Lab copies movies, images, and exports into `Film Lab/<lot>/` under that folder.

- Film Lab does **not** log into OneDrive or Google.
- No hosted Drive API. No credits.
- If the folder is missing (Drive offline / unmounted), backup skips that target and says so. The local library stays.
- Connect only when you want a second copy. Offline work never depends on Drive.

Windows examples:

`C:\Users\Liam\OneDrive`

`C:\Users\Liam\Google Drive`
