# Film Lab CLI skills (stub)

Companion notes for Claude Code, OpenClaw, Hermes, and Cursor. **Personal use. Localhost only.**

Package: **film-lab-cli** — invoke `python -m film_lab.cli`.

This is **not** a hosted video-product CLI and **not** a paid skill pack. Film Lab has no credits.

```bash
python -m film_lab.cli init
python -m film_lab.cli skills
```

Point the agent at `http://127.0.0.1:43123`. Do not sign in to a cloud studio.

Planned tools: `list_projects`, `list_shots`, `generate_shot`, `write_draft`, `list_connectors`, `enhance_prompt`.

Optional keys you already own (environment only):

- `FILM_LAB_ANTHROPIC_API_KEY` / `ANTHROPIC_API_KEY`
- `FILM_LAB_OPENAI_API_KEY` / `OPENAI_API_KEY`
- `FILM_LAB_XAI_API_KEY` / `XAI_API_KEY`
