# Playback vs Direct

Take Board has two modes. They never mix. Chrome matches the rest of Film Lab (purple + soft cyan) — not a red Darkroom Suite. Regular vs 18+ Explicit stays a filming-mode toggle.

## Playback (default)

Click a take to **play**. Play, pause, and scrub only.

Pause **freezes** the player. It does **not** edit the take. After you pause, **click the person** (or the head) to open **Dream about…**. Pick **Enter dream** (they are inside the sequence) or **Thought bubble** (overlay on the sleeping shot). See [DREAM.md](DREAM.md).

## Direct

Enter only with the button labeled **Mark & Direct**. Helper text: **Fix this frame**.

While Directing, the banner reads:

**Directing — changes will make a new take**

Then:

1. Pause or scrub to study the beat.
2. Set **Mark at (seconds)** and **Use this second** if you need a later frame.
3. Circle / square / lasso the region. On a sleeping take, mark the **head** to **Enter dream**.
4. Write the note (head fills **Enter dream.**).
5. **Apply**, **Enter dream**, or **Regenerate**. See [DREAM.md](DREAM.md).

**Exit Direct** returns to Playback. The old take stays on the board. Regenerate forks a new take.

## What is not Fix this frame

- Pause
- Click a take (that is Play)
- Cast faces → **Director Note** (performance)
- Motion **Revise this take** (Director Note + Pose on Motion Desk)

Zero credits.
