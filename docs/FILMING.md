# Filming modes

Film Lab has a **hard split** between everyday story and adult intimacy.

## Regular | 18+ Explicit

Pick the mode **before** the content-intensity dial.

| Mode | Who may appear | Intimacy / nude / sex |
| --- | --- | --- |
| **Regular** | Adult, Mom, Dad, Teen, Child, Infant | Locked. Non-sexual only (bus, walk home, kitchen, aerial outdoors). |
| **18+ Explicit** | Adult / Mom / Dad with Age (years) 18+ | Unlocked. Same adult explicit tools as before. |

Under-18 **roles** (Teen, Child, Infant) never unlock explicit tools, even if someone types an adult age by mistake. The bible rejects Teen 18+ and Adult under 18.

- artistic nude, intimate sex, explicit / pornographic
- frank+ intensity (≥ 0.45)
- undress through motion / into explicit sex
