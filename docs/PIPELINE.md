# AI Production Pipeline

Home card → one desk. **Enhance | Pose | Animate** on the **same shot**.

Upload the still once. Changing steps does **not** ask for another file. **Back to Home** returns to the hub.

Zero credits. Local ComfyUI SVD-XT. Sidecar Off → honest toast, no Ken Burns auto-fallback. Intimate / explicit: adult 18+ ONLY.

## Steps

| Step | What it does |
| --- | --- |
| **Enhance** | Short prompt → dense img2vid line. Three dropdowns: **Aspect**, **Resolution** (480p–4K including 1440p), searchable **Lighting** (or skip). No button grids. Same still. |
| **Pose** | Body / hands / face on **this** still. Face lock stays. Skip on a can or poster. |
| **Animate** | Same SVD-XT path as Motion Desk. The take lands here and on the full desk. |

## Same shot

Gradio cannot put one Image in two tabs. Pipeline copies the still **by path** onto Motion Desk. That is not a second upload.

Quality, duration, Director Note, World Note, and Mark stay on **Full Motion Desk**.

Hub stays **15 cards**. This card replaced Motion Desk on Home. The Motion Desk tab is still there.
