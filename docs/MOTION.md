# Motion Desk — any still → Animate

The Home card **AI Production Pipeline** opens one desk: **Enhance | Pose | Animate** on the **same shot** (no re-upload). See [PIPELINE.md](PIPELINE.md).

**Motion Desk** is the full image→video path (Quality, duration, Director Note, Mark). Drop **any still** and **Animate**: people, products, cans, posters. Local SVD-XT. Zero credits. **No marketplace.**

Product + person ads (avatar, placement, hook→CTA) live on **UGC Ads Desk**. See [UGC.md](UGC.md).

## Still kind

| Kind | What to do |
| --- | --- |
| **Person** | Pose / face lock / Director Note as usual. Intimate / explicit: adult 18+ only. |
| **Product / object** | Skip Pose. Face lock off. Prompt the object (lid lifts, label holds). |
| **Poster / ad still** | Same as object. The poster is the start frame. |

Switching still kind clears or restores the bible cast so a can is not forced through Alison's face lock.

## Multi-beat product motion

Example: **can opens alone** → then a person **picks up and pours**.

1. **Mark & Direct** — Animate beat 1 on Motion. Take Board Playback. **Mark & Direct** · Fix this frame. Note the pour. **Regenerate**. Old take stays. [MARK.md](MARK.md) · [PLAYBACK.md](PLAYBACK.md)
2. **Multi-shot stitch** — UGC Ads Desk **Push two beats → Motion Desk**. Animate each shot. Cinema Desk stitch.

Both paths are local. There is no hosted UGC shop.
