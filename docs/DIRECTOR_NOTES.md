# Director Note + World Note

Performance direction and mise-en-scène on **Motion Desk** and **Take Board**. Apply folds into **Enhance → Pose → Animate**. Zero credits.

## Director Note (Character)

Click any Character Bible face. A popup opens:

- **Emotion** — acting feeling (tenderness, tension, grief, …)
- **Micro-expression** — the face (swallow, glance, brow flick). Same catalog as Pose, Character Bible, Voice, Writing.
- **Behavior (full human)** — the whole body (weight shift, reach then hold). Not a hosted face-puppet.
- **Acting beats** — what the actor does (hold the look, don't rush the line). **Type or speak** into the same box (mic on the note). Then Apply.
- **Wardrobe through motion** — clothes stay, **undress through motion**, or **into explicit sex**

A clothed intimate still can become explicit sex **in the clip** when the intensity dial is **Explicit / adult study** and every note character is 18+. Film Lab will not lock wardrobe on that path.

Film term: **performance direction**.

The picker may include **any age** for normal non-sexual acting, emotion, and placement. It does not filter the bible to adults-only.

## World Note (Background)

Separate control. Environment direction:

- Weather, thunder, earth, wind
- Outdoor / aerial plate (street, sky, bus stop, walk home, drone aerial)
- Setting
- Placement (who stands where)
- **Prop action** — pick up book / glass / door from the still or a paused frame. Same catalog as Mark & Direct. See [PERFORMANCE.md](PERFORMANCE.md).

Film term: **mise-en-scène / environment direction**.

Same Apply path as Director Note.

Filming mode **Regular | 18+ Explicit** sits before the intensity dial. Regular is non-sexual story (family roles allowed). Intimate tools unlock only in 18+ Explicit with an adult 18+ cast. See [FILMING.md](FILMING.md) and [SET.md](SET.md).

## Safety — intimate / explicit is adult 18+ ONLY

Director Notes on a younger face are performance and placement only.

**Never** route minors into intimacy or porn intensity. The intensity dial and intimacy mode copy say this on Motion Desk, Take Board, and Writing Studio.

If intimacy is nude / sex / explicit / pornographic, or content intensity is frank and above (~0.45+), Apply / Enhance / Animate / Take Board **block** any note character who is under 18 or not a confirmed adult.

**Undress through motion / into explicit sex** always needs the Explicit dial (≥ 0.90) and a confirmed adult 18+ cast. The start still may stay clothed.

## Click take → new take

After Animate, **Revise this take** on Motion (or click a Motion gallery take) opens Director Note + Pose. That is **not** Fix this frame.

On **Take Board**, click a take to **play**. Pause never edits. **Mark & Direct** · Fix this frame enters Direct. Banner: *Directing — changes will make a new take.* **Regenerate** forks a new shot. The old take stays. See [PLAYBACK.md](PLAYBACK.md).

## Where it lands

Notes save on the project as `director_notes.json`. They inject into:

- The Motion prompt (folded lines)
- Prompt Enhancement
- Compose local prompt / SVD-XT
- New Take Board variants (copied onto each take)

Pose Desk still edits the still. Notes ride the prompt after Apply.

Mic: [VOICE_NOTES.md](VOICE_NOTES.md). Typed and spoken land in the same note.
